Privacy Policy

ClipForge · effective 20 September 2026

ClipForge is a personal automation tool that runs locally on its operator's computer. This policy describes which data the tool accesses, how it stores that data, and for how long.

There is no server. ClipForge does not host a service, does not maintain a remote database and does not transmit data to third parties. Everything described below is stored only on the operator's own computer.

1. Data the tool accesses

DataSourcePurpose
TikTok access token and refresh token TikTok, via OAuth authorization granted by the operator Authenticate video publishing requests
Account identifier (open_id) and display name TikTok Confirm which account the post will be made to
Publish status and published video identifier TikTok Record whether the upload completed and prevent duplicate posts
Public clip metadata (title, channel, view count, duration) Official Twitch API Select which clips will be edited
Video files and transcripts Generated locally from the clips Produce the captioned vertical video

2. Data the tool does NOT access

  • Direct messages, contacts, followers, or any private content of the account.
  • Data belonging to any other TikTok user.
  • Passwords. Authentication is performed exclusively through OAuth; the tool never receives or stores the account password.
  • Location, device data, or advertising identifiers.

3. Where the data is stored

In files on the local disk of the operator's computer. Access tokens are kept in a separate credentials file, outside any code repository and never shared.

4. Sharing

No data is sold, transferred, synchronized to any cloud, or shared with third parties. The only network communications the tool performs are with the official Twitch API, the official TikTok API and, where applicable, the language-model service used to draft titles and descriptions — which receives only the text of the clip transcript, never account data.

5. Retention

  • Source videos: deleted automatically 7 days after processing.
  • Published videos and metadata: kept for as long as the operator wishes; removable at any time by deleting the local folders.
  • TikTok tokens: kept only while the authorization remains active. They are deleted when the operator revokes access or deletes the credentials file.

6. How to revoke access

At any time, from the TikTok app, under Settings and privacy → Security and permissions → Manage app permissions. Revoking invalidates the tokens immediately and the tool can no longer publish. To erase the local data, delete the installation folder.

7. Third-party content and attribution

The clips processed are public content from third-party live streams, obtained through the official Twitch API. Every post credits the source channel on screen and in the description. Only channels that expressly authorize the use of their clips are included. Takedown requests from original creators are honored.

8. Children

The tool is not directed at children under 13 and does not collect data from children.

9. Changes

Changes to this policy are published on this same page, with the effective date updated at the top.
