Política de Privacidade

ClipForge · vigente desde 20 de setembro de 2026

O ClipForge é uma ferramenta pessoal de automação executada localmente no computador do seu operador. Esta política descreve quais dados a ferramenta acessa, como os armazena e por quanto tempo.

Não existe servidor. O ClipForge não hospeda serviço, não mantém banco de dados remoto e não transmite dados a terceiros. Tudo o que é descrito abaixo fica gravado apenas no computador do operador.

1. Dados que a ferramenta acessa

DadoOrigemPara que serve
Token de acesso e token de atualização do TikTok TikTok, via autorização OAuth concedida pelo próprio operador Autenticar as chamadas de publicação de vídeo
Identificador da conta (open_id) e nome de exibição TikTok Confirmar em qual conta a publicação será feita
Estado da publicação e identificador do vídeo publicado TikTok Registrar se o envio foi concluído e evitar envios duplicados
Metadados públicos de clipes (título, canal, visualizações, duração) API oficial da Twitch Selecionar quais clipes serão editados
Arquivos de vídeo e transcrições Gerados localmente a partir dos clipes Produzir o vídeo vertical legendado

2. Dados que a ferramenta NÃO acessa

  • Mensagens diretas, contatos, seguidores ou qualquer conteúdo privado da conta.
  • Dados de outras pessoas usuárias do TikTok.
  • Senhas. A autenticação é feita exclusivamente por OAuth; a ferramenta nunca recebe nem armazena a senha da conta.
  • Localização, dados de dispositivo ou identificadores de publicidade.

3. Onde os dados ficam

Em arquivos no disco local do computador do operador. Os tokens de acesso ficam em um arquivo de credenciais separado, fora de qualquer repositório de código e não compartilhado.

4. Compartilhamento

Nenhum dado é vendido, cedido, sincronizado com nuvem ou compartilhado com terceiros. As únicas comunicações de rede que a ferramenta realiza são com a API oficial da Twitch, a API oficial do TikTok e, quando aplicável, o serviço de modelo de linguagem usado para redigir títulos e descrições — ao qual é enviado apenas o texto da transcrição do clipe, nunca dados de conta.

5. Retenção

  • Vídeos de origem: apagados automaticamente 7 dias após o processamento.
  • Vídeos publicados e metadados: mantidos enquanto o operador desejar; removíveis a qualquer momento apagando as pastas locais.
  • Tokens do TikTok: mantidos apenas enquanto a autorização estiver ativa. São apagados quando o operador revoga o acesso ou exclui o arquivo de credenciais.

6. Como revogar o acesso

A qualquer momento, pelo aplicativo do TikTok, em Configurações e privacidade → Segurança e permissões → Gerenciar permissões de aplicativos. A revogação invalida os tokens imediatamente e a ferramenta deixa de conseguir publicar. Para eliminar os dados locais, basta apagar a pasta de instalação.

7. Conteúdo de terceiros e atribuição

Os clipes processados são conteúdo público de transmissões de terceiros, obtidos pela API oficial da Twitch. Toda publicação credita o canal de origem na imagem do vídeo e na descrição. Apenas canais que autorizam expressamente o uso de seus clipes são incluídos. Pedidos de remoção feitos pelo criador original são atendidos.

8. Menores de idade

A ferramenta não se destina a menores de 13 anos e não coleta dados de menores.

9. Alterações

Mudanças nesta política são publicadas nesta mesma página, com a data de vigência atualizada no topo.
